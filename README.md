# SaaS Scout 🚀

SaaS Scout helps you find new and useful software tools — fast. Whether you're building a startup, managing a team, or just love trying out new apps, we make it easy to discover the latest software worth your time.

## What It Does

- Shows you new SaaS tools every day
- Gives you honest pros and cons
- Lets you filter tools by your role (Founder, IT Manager, Developer)
- Helps you compare features, pricing, and more
- Scores each tool based on design, value, originality, and more

## Features ✨

### 🎯 Smart Discovery

Quickly find tools that match your needs by browsing categories or filtering by who you are and what you care about.

### 📊 Honest Scoring

We rate each tool based on:
- Design
- Value for money
- Features
- Originality
- Clarity
- Who's behind it

### 🧠 Quick Quiz

Not sure what you need? Take a short quiz and get personalized tool suggestions based on your role, budget, and preferences.

## How We Built It 💻

- Next.js + React for the frontend
- TypeScript for safer code
- TailwindCSS for styling
- Product Hunt API for fresh daily launches
